Seletores e atributos

Para selecionar o valor do atributo, é necessario colocar valor que tu deseja no CSS.
Para todos o valores colocar= ~ ex: isso no html - atributo="sim nao teste" no css - [atributo~="nao"] { aqui vai os stilos desejado }


Para os valores com um traço (ex:valor-1) no primeiro valor colocar= | ex: isso no html - atributo="valor-1 valor-2" no css - [atributo|="valor-1"] { }


Para selecionar o valor que começa, pode ser apenas a inicial do valor (ex:sim, colocar "s" ou "si"), para esse atributo colocar= ^ ex: isso no html - atributo="sim nao teste" no css - [atributo^="si"] { }


Para selecionar o valor com que termina o valor(ex:"teste" colocar só o final do valor "ste"), colocar= $ ex: isso no html - atributo="sim nao teste" no css - [atributo$="ste"] { }


Para o selecionar o valor que contem (ex:"valor" o valor contem a letra "a") colocar= * ex: isso no html - atributo="valor" no css - [atributo*="a"] { }
