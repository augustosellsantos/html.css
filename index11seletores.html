Seletores pai e filho

Seletores no CSS - pais e filhos, ex: .nomedaclass > .nomedaoutraclass { } Para ser bem especifico no CSS, deve colocar esse seletor (>) como no exemplo a cima.

Seletores irmãos

Seleciona um elemento diretamente seguido de outro elemento tu deve colocar o seletor (+), como no exemplo a baixo: Ex: .pai h1+p { } Para selecionar todos elementos que são irmão do seguinte elemento, colocar o seletor (~), como no exemplo seguinte: Ex: .pai h1~p { }
