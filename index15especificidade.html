Compreendendo a Especificidade no CSS

A ordem com maior especificidade dos elementos, classes e IDs no CSS: ID, Class, atributos e pseudo-classes, Elementos e pseudo-elementos.

Essa palavra !important sobreescreve qualquer outro valor no CSS

Regra de aplicação no CSS é da seguinte forma: primeiro a especificidade, depois o empate - em caso que empate na especificidade, style - ganha dos dois anteriores e por último o !important - ganha de todos.
